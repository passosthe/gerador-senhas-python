# 🔐 Gerador de Senhas Aleatórias em Python

Este é um projeto simples desenvolvido em Python para gerar senhas aleatórias e seguras. O programa permite ao usuário definir o comprimento da senha e escolher quais tipos de caracteres incluir (letras, números e/ou símbolos).

O projeto é executado via linha de comando (CLI) e foi construído como parte do meu portfólio para demonstrar o domínio dos fundamentos de Python, como módulos básicos, manipulação de strings, e tratamento de entrada do usuário.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** Python
* **Módulos:** `random`

## ✨ Funcionalidades

* Permite definir o comprimento exato da senha.
* Oferece opções para incluir/excluir:
    * Letras (maiúsculas e minúsculas).
    * Números.
    * Símbolos.
* Inclui tratamento de erro para entradas inválidas (ex: digitar texto em vez de um número para o comprimento).
* Garante que a senha gerada utiliza o "pool" exato de caracteres solicitado.
